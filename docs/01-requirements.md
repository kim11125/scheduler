# 01. 요구사항 정의

## 1. 서비스 목적

관리자 승인 기반의 폐쇄형 개인 스케줄 관리 웹앱이다.
누구나 회원가입을 신청할 수 있지만, 관리자가 승인한 사용자만 서비스를 이용할 수 있다.
각 사용자는 본인의 일정만 관리하며, 다른 사용자의 일정은 열람할 수 없다.
관리자는 전체 사용자의 일정을 조회하고 관리할 수 있다.

---

## 2. 사용자 유형

| 유형 | 설명 |
|------|------|
| 비로그인 사용자 | 로그인 화면, 회원가입 화면만 접근 가능 |
| USER + PENDING | 가입 신청 후 승인 대기 중. 일정 기능 사용 불가 |
| USER + ACTIVE | 승인 완료. 본인 일정 등록/조회/수정/삭제 가능 |
| USER + REJECTED | 가입 거절됨. 안내 화면만 표시 |
| USER + DISABLED | 계정 비활성화됨. 안내 화면만 표시 |
| ADMIN + ACTIVE | 전체 사용자 관리 및 전체 일정 조회/수정/삭제 가능. 본인 일정 등록도 가능 |

---

## 3. 핵심 기능 (MVP)

### 3-1. 인증

- 회원가입 신청 (아이디, 비밀번호, 이름)
- 로그인 (JWT Access Token 발급)
- 로그아웃
- 현재 사용자 정보 조회 (`/api/auth/me`)

### 3-2. 관리자 기능

- 가입 신청 사용자 목록 조회 (PENDING)
- 사용자 승인 / 거절 / 비활성화 / 재활성화
- 전체 사용자 목록 조회
- 전체 일정 조회 (사용자/날짜/카테고리 필터)
- 특정 사용자의 일정 조회
- 모든 사용자 일정 수정/삭제
- 본인 일정 등록/조회/수정/삭제

### 3-3. 일반 사용자 기능

- 월간 캘린더 화면에서 날짜 클릭 후 일정 등록
- 본인 일정 목록 조회 (날짜 단위)
- 일정 상세 조회
- 일정 수정
- 일정 삭제

### 3-4. 일정 입력 항목

- 날짜 (필수)
- 제목 (필수)
- 카테고리 (필수): 야구 / 농구 / 축구 / 여자배구 / 남자배구 / 기타
- 홈/원정 (야구 선택 시 필수)
- 메모 (선택)

---

## 4. 제외 기능 (MVP 범위 밖)

- 일정 시간(시작/종료 시간) 관리
- 장소(location) 입력
- 일정 공유 또는 제출 기능
- 사용자 간 일정 열람
- 알림(Push/Email)
- 달력 외부 서비스 연동 (Google Calendar 등)
- 반복 일정 (매주, 매월 등)
- 첨부파일
- 비밀번호 찾기 / 이메일 인증
- 소셜 로그인

---

## 5. MVP 범위 요약

| 구분 | 포함 여부 |
|------|-----------|
| 회원가입 신청 | O |
| 관리자 승인/거절/비활성화 | O |
| JWT 로그인 (Access Token) | O |
| 월간 캘린더 + 날짜 클릭 일정 입력 | O |
| 일정 CRUD (날짜/제목/카테고리/메모) | O |
| 야구 홈/원정 입력 | O |
| 관리자 전체 일정 조회/수정/삭제 | O |
| AuditLog 기록 | O |
| Refresh Token | X |
| 알림 기능 | X |
| HTTPS | X (향후 적용 가능하도록 구조 준비) |
| PWA | X (향후 적용 가능하도록 구조 준비) |

---

## 6. 향후 확장 기능

- HTTPS 적용 (도메인 확보 후 Let's Encrypt)
- PWA 적용 (홈 화면 추가, 오프라인 캐시)
- Refresh Token 도입
- 비밀번호 변경 기능
- 관리자 알림 (새 가입 신청 발생 시)
- 일정 통계/집계 화면 (카테고리별 월간 현황 등)
- 사용자 프로필 수정
- 비밀번호 초기화 (관리자 처리)
